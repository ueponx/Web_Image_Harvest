# Page Image Downloader

ウェブページ内のすべての画像を簡単にダウンロードするためのChrome拡張機能です。

## 機能

- ワンクリックでページ内のすべての画像をダウンロード
- 画像はページタイトルとタイムスタンプ付きのフォルダに自動整理
- オリジナルの画像形式を保持したままダウンロード
- 様々な画像形式に対応（詳細は下記参照）

## 対応画像フォーマット

| フォーマット | 拡張子 | 主な用途 | 特徴 |
|------------|-------|---------|------|
| JPEG/JPG   | .jpg, .jpeg | 写真、一般的なウェブ画像 | 非可逆圧縮、高圧縮率 |
| PNG        | .png | ロゴ、透過画像 | 可逆圧縮、透明度対応 |
| GIF        | .gif | アニメーション、シンプルな画像 | アニメーション対応、256色制限 |
| SVG        | .svg | ベクター画像、アイコン | 拡大縮小可能、XML形式 |
| WebP       | .webp | 最新のウェブ画像 | JPEGより高圧縮、透明度対応 |
| BMP        | .bmp | ビットマップ画像 | 無圧縮、高品質 |
| ICO        | .ico | ファビコン、アイコン | 複数サイズ格納可能 |
| AVIF       | .avif | 最新のウェブ画像 | 高圧縮率、高品質 |
| TIFF       | .tif, .tiff | 印刷用画像 | 高品質、多層対応 |

## インストール方法

### 開発モードでのインストール

1. このリポジトリをクローンまたはダウンロード
2. Chromeブラウザで `chrome://extensions/` にアクセス
3. 右上の「デベロッパーモード」を有効化
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. ダウンロードしたフォルダを選択

## 使用方法

1. 画像をダウンロードしたいウェブページにアクセス
2. Chrome ツールバーの「Page Image Downloader」アイコンをクリック
3. ポップアップ内の「すべての画像をダウンロード」ボタンをクリック
4. 画像はChromeのダウンロードフォルダ内のタイムスタンプ付きフォルダに保存されます

## プロジェクト構成

```
page-image-downloader/
├── manifest.json           // 拡張機能の設定ファイル
├── popup.html              // ポップアップUI
├── popup.js                // ポップアップの制御スクリプト
├── background.js           // バックグラウンドで実行されるスクリプト
└── images/                 // アイコン画像フォルダ
    ├── icon16.png          // 16×16サイズのアイコン
    ├── icon48.png          // 48×48サイズのアイコン
    └── icon128.png         // 128×128サイズのアイコン
```

## 注意事項

- `<img>` タグで表示されている画像のみをダウンロードします
- CSS背景画像や、JavaScript経由で動的に表示される画像は取得できない場合があります
- ウェブサイトによっては、CORS制限により一部の画像がダウンロードできない場合があります
